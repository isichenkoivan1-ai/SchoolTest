# 🎲 Loot Hunter

**Loot Hunter** — невелика консольна RNG-гра на Python, у якій гравець відкриває скрині, збирає випадкові предмети різної рідкості, заробляє монети та покращує свою удачу, щоб отримувати цінніший лут.

## 🎮 Особливості

- 🎁 Відкриття скринь за монети.
- 🎲 Система випадкових нагород (RNG).
- 💎 5 рівнів рідкості предметів.
- 🎒 Інвентар для зберігання отриманого луту.
- 💰 Продаж предметів за монети.
- 🍀 Система покращення удачі.
- 📊 Перегляд таблиці рідкостей.
- 🖥️ Простий консольний інтерфейс.
- 📦 Не потребує встановлення сторонніх бібліотек.

## 💎 Рідкості предметів

| Рідкість | Шанс | Приклад предмета | Вартість |
|---|---:|---|---:|
| Common | 60% | Старий камінь | 5 |
| Uncommon | 25% | Срібний перстень | 20 |
| Rare | 10% | Кристал | 75 |
| Epic | 4% | Магічний меч | 250 |
| Legendary | 1% | Корона дракона | 1000 |

## 🕹️ Як грати

1. Запусти гру.
2. Використовуй меню для вибору дії.
3. Відкривай скрині за 25 монет.
4. Отримуй випадкові предмети.
5. Продавай предмети, щоб заробити монети.
6. Купуй покращення удачі, щоб підвищити шанси отримання рідкісного луту.
7. Спробуй отримати всі предмети та легендарну нагороду!

## 🛠️ Покращення удачі

За монети можна купувати покращення удачі.

- Одне покращення дає **+20% удачі**.
- Ціна покращення залежить від поточного рівня удачі.
- Максимальний рівень удачі — **200%**.
- Удача збільшує вагу шансів рідкісних предметів у системі випадкових нагород.

## 🚀 Запуск

### Вимоги

- Python 3.8 або новіший.
- Термінал або консоль.

### Інструкція

Клонуй репозиторій:

```bash
git clone https://github.com/USERNAME/loot-hunter.git
```

Перейди до папки проєкту:

```bash
cd loot-hunter
```

Запусти гру:

```bash
python loot_hunter.py
```
